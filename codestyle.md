# Code Style

## Source

The Python code in this project follows the official PEP 8 - Style Guide for Python Code.

- Reference: https://peps.python.org/pep-0008/

## Project Conventions

- Use 4 spaces for indentation, not tabs.
- Function and variable names use snake_case, e.g. `fetch_history`.
- Class names use CapWords, e.g. `ExpressionParser`.
- Each function should do one thing and keep responsibilities clear.
- Use meaningful names instead of single-letter names like `a`, `b`, `x`.
- Add short comments for complex logic.
